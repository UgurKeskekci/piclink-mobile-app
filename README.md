# Piclink

Piclink is a mobile application that provides a platform for users to share and explore photos within events.

## Features

- **Event Creation:** Users can create events and invite others to join.
- **Event Sharing:** Share events with friends and family via QR code or invitation link.
- **Photo Sharing:** Share photos within events and explore photos shared by others.
- **Event Interaction:** Like photos, comment on photos, and interact with other users within events.
- **Profile Management:** Users can manage their profiles, including setting a profile picture and username.
- **Security:** Secure login system with password encryption and password reset functionality.

## Getting Started

To get started with Piclink, follow these steps:

1. **Clone the Repository:** Clone the Piclink GitHub repository to your local machine.

git clone https://github.com/your_username/piclink.git


2. **Install Dependencies:** Navigate to the project directory and install the necessary dependencies.

cd piclink
npm install


3. **Run the Application:** Start the application locally.

npm start


4. **Explore and Contribute:** Explore the codebase, test the application, and contribute to the project by submitting pull requests.

## Technologies Used

- React Native: Frontend framework for building the mobile application.
- Firebase: Backend services for authentication, database management, and file storage.
- QR Code Generator: Library for generating QR codes for event sharing.
- Redux: State management library for managing application state.
- Axios: HTTP client for making API requests.
